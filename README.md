## 📝 说明

- 本仓库为春凯外贸业务内部工具集合
- 所有工具均为纯前端 HTML 页面，无需后端服务
- 数据内置在各页面的 JavaScript 中
- 更新数据直接修改对应 HTML 文件即可

## 🔧 更新方式

1. 在 GitHub 仓库页面点击对应文件名
2. 点击右上角铅笔图标 ✏️ 进入编辑
3. 修改完成后拉到页面底部点击 **Commit changes**
4. GitHub Pages 会自动重新部署（约1-2分钟生效）
